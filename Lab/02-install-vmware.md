# Install VMware Workstation

## Objective
The objective of this step is to install VMware Workstation on the host machine to prepare the virtualization environment for the Wazuh lab.

VMware Workstation will be used to create and run the virtual machines required for the project, starting with the Ubuntu server where Wazuh will be installed.

## Download VMware Workstation

### Step 1
Download the VMware Workstation installer from the official website.

First, create an account in Broadcom:

[Broadcom Sign In](https://access.broadcom.com/default/ui/v1/signin/)

### Step 2
Once you create the account and sign in, go to **My Downloads**, then click **Free Software Downloads Available HERE**.

![Step 2](https://github.com/user-attachments/assets/b7796b91-eaa8-423a-b268-d08022915ce5)

### Step 3
Scroll down and select **VMware Workstation Pro**.  
Then choose **VMware Workstation Pro 17.0 for Windows** and select a version that is not the newest one.

![Step 3 - Option 1](https://github.com/user-attachments/assets/2a2e049c-9a56-4188-8e7b-d709c049ead4)

![Step 3 - Option 2](https://github.com/user-attachments/assets/dd7da9e2-e835-4a6c-a57b-143295d9903)

### Step 4
Click **Download**.

![Step 4](https://github.com/user-attachments/assets/d6f59218-3a83-4d56-a5b2-ed38f363b218)

## Install VMware Workstation

### Step 5
Locate the installer file on the host machine.

### Step 6
Right-click the installer and select **Run as administrator**.

### Step 7
Wait for the setup wizard to open.

### Step 8
Click **Next** to begin the installation.

### Step 9
Accept the license agreement.

### Step 10
Select the standard installation option.

### Step 11
Continue with the default settings.

### Step 12
Click **Install** to start the installation process.

### Step 13
Wait for the installation to complete.

### Step 14
Click **Finish** when the setup is done.

### Step 15
Restart the host machine if required.

### Step 16
Open VMware Workstation and confirm it starts correctly.
